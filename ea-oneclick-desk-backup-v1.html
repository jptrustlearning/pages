HOW TO INSTALL

วิธีติดตั้งบน MetaTrader 5

ทำครั้งเดียว ใช้เวลาไม่เกิน 2 นาที — ขั้นตอนเหมือนกันทุกโบรกเกอร์

1

ดาวน์โหลดไฟล์

กดปุ่มด้านบนเพื่อโหลดไฟล์ JPT_OneClick_Desk_v303.ex5 เก็บไว้ในเครื่อง

2

เปิดโฟลเดอร์ของ MetaTrader 5

เปิดโปรแกรม MT5 → เมนู File → Open Data Folder → เข้าโฟลเดอร์ MQL5 → Experts

3

วางไฟล์แล้วรีเฟรช

คัดลอกไฟล์ .ex5 ไปวางในโฟลเดอร์ Experts จากนั้นกลับไปที่ MT5 คลิกขวาที่หน้าต่าง Navigator แล้วเลือก Refresh

4

ลากลงกราฟ แล้วเปิด AutoTrading

ใน Navigator → Expert Advisors จะเห็นชื่อ JPT OneClick Desk ให้ลากลงบนกราฟที่ต้องการ แล้วกดปุ่ม AutoTrading (ปุ่มด้านบนของ MT5) ให้เป็นสีเขียว — ถ้าเห็นหน้ายิ้มมุมขวาบนของกราฟ แปลว่าใช้งานได้แล้ว

  • ชื่อไฟล์และเงื่อนไขของแต่ละโบรกเกอร์ต่างกัน ถ้าส่งคำสั่งไม่ผ่าน ให้ตรวจ ขนาดล็อตขั้นต่ำ และ ระยะ Stop Level ของโบรกเกอร์ก่อน
