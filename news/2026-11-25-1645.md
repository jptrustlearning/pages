## เย็นวันพุธ: SET ช่วงบ่ายลงลึกเกือบ 22 จุด แถว 1,429.76 (−1.49%) ต่ำกว่าระดับ 1,430 ที่โบรกให้ดู · แรงขายกระจุกหุ้นใหญ่ GULF DELTA KBANK · กังวลภาษีสหรัฐฯ สองเรื่องซ้อน — ภาษีนำเข้ารอบใหม่ 16 ประเทศ และภาษีบริษัทที่ไปตั้งศูนย์ข้อมูลนอกประเทศ · ต่างชาติขายสุทธิเมื่อวาน 5,269 ล้านบาท ยอดซื้อสุทธิทั้งปีเหลือราว 7,770 ล้านบาท

ภาพของตลาดหุ้นไทยช่วงบ่ายวันนี้แย่ลงจากภาคเช้าที่ลบเพียงราว 12 จุด ข้อมูลอัพเดทช่วงบ่ายราว 15:00 น. ที่ MGR Online รายงาน ดัชนี SET อยู่ที่ 1,429.76 จุด ลบ 21.89 จุด (−1.49%) มูลค่าซื้อขายราว 47,760 ล้านบาท ซึ่งหลุดลงมาต่ำกว่าระดับ 1,430 จุดที่โบรกเกอร์หลายแห่งให้เป็นจุดรับของวัน ส่วนสำนักข่าวข่าวหุ้นพาดหัวช่วงบ่ายว่าดัชนี "รูด 20 จุด" ตัวเลขทางการตอนปิดตลาด 16:30 น. (รวมช่วงสุ่มเวลาปิด) ยังไม่ออกตอนที่เขียนบทนี้ จึงขอให้ถือระดับนี้เป็นภาพช่วงบ่าย ไม่ใช่ราคาปิด

สิ่งที่ต่างจากเมื่อวานคือแรงขายไม่ได้มาจากหุ้นอิเล็กทรอนิกส์อย่างเดียว แต่ลามไปหุ้นโรงไฟฟ้าและนิคมอุตสาหกรรมที่เคยเป็น "หุ้นธีมศูนย์ข้อมูล" และหุ้นธนาคารขนาดใหญ่ ทำให้ดัชนีที่มีหุ้นกลุ่มนี้น้ำหนักสูงอ่อนแรงกว่าช่วงเช้า ทั้งที่เช้านี้ SET ลบน้อยกว่าตลาดเพื่อนบ้านในเอเชียมาก

**ปัจจัยที่ขับเคลื่อน**

- **ภาษีสหรัฐฯ สองชั้น** ชั้นแรกคือการสอบสวน "กำลังการผลิตล้นเกิน" ตาม Section 301 (มาตรา 301 กฎหมายการค้าสหรัฐฯ) กับคู่ค้า 16 ประเทศรวมไทย ที่จะเป็นฐานภาษีนำเข้าชุดใหม่แทนชุดที่ศาลสูงสุดตัดสินว่าใช้อำนาจไม่ได้ ชั้นที่สองคือคำขู่ของ Trump ว่าจะเก็บ "ภาษีก้อนใหญ่" กับบริษัทสหรัฐฯ ที่ไปสร้างศูนย์ข้อมูลนอกประเทศ ซึ่งแตะธีมการลงทุนที่ตลาดไทยหวังพึ่งในปี 2027 โดยตรง
- **หุ้นเทคโลกถูกขายต่อ** Nvidia ลบ 5.9% เมื่อคืน ดัชนีหุ้นชิปสหรัฐฯ ลบราว 7.9% และฟิวเจอร์สหุ้นเทคสหรัฐฯ เย็นนี้ยังลบราว 1.4–2% ⇒ หุ้นห่วงโซ่ชิ้นส่วนอย่าง DELTA ยังถูกลดน้ำหนัก
- **ดอกเบี้ยสหรัฐฯ** ตลาดให้โอกาสเฟดขึ้นดอกเบี้ยในการประชุม ธ.ค. ราว 93–98% ทำให้ผลตอบแทนของเงินดอลลาร์ระยะสั้นน่าสนใจกว่า เป็นแรงดึงเงินออกจากตลาดเกิดใหม่ที่การเติบโตต่ำอย่างไทย
- **รอตัวเลขคืนนี้** PCE เดือน ต.ค. และ GDP ไตรมาส 3 ออกพร้อมกัน 20:30 น. ก่อนตลาดสหรัฐฯ ปิดวันขอบคุณพระเจ้า ทำให้นักลงทุนไม่อยากถือความเสี่ยงข้ามคืน

**ผลกระทบเชิงโครงสร้าง**

- หุ้นที่ตลาดเคยใช้เป็น "ทางเลือกของไทยในธีม AI" มีสองกลุ่ม คือชิ้นส่วนอิเล็กทรอนิกส์ (นำโดย DELTA) กับโรงไฟฟ้าและนิคมฯ ที่รับลูกค้าศูนย์ข้อมูล (นำโดย GULF) วันนี้ทั้งสองกลุ่มโดนพร้อมกันด้วยเหตุผลคนละแบบ ⇒ ธีม AI ของไทยกำลังถูกตั้งคำถามทั้งฝั่งความต้องการชิปและฝั่งนโยบาย
- ยอดซื้อสุทธิทั้งปีของต่างชาติที่หดจาก 75,000 เหลือราว 7,770 ล้านบาท บอกว่าเงินต่างชาติที่เข้ามาช่วงต้นปีเกือบทั้งหมดถอนกลับแล้ว ถ้าขายต่ออีกไม่กี่วันยอดทั้งปีจะกลับเป็นขายสุทธิ ซึ่งจะเป็นปีที่สี่ติดต่อกัน

**ความเสี่ยงที่ต้องระวัง**

- ถ้า PCE คืนนี้สูงกว่าคาด ตลาดอาจเริ่มคิดถึงการขึ้นดอกเบี้ยต่อในปี 2027 ⇒ ดอลลาร์แข็ง บาทอ่อน เงินไหลออกต่อ
- รายชื่อประเทศและอัตราภาษีตาม Section 301 ยังไม่ประกาศ ถ้าไทยโดนอัตราสูง หุ้นส่งออกอิเล็กทรอนิกส์ อาหารแปรรูป และเหล็กจะถูกกดเพิ่ม

**3 สถานการณ์ที่อาจเกิด (ประเมินโดย JP Trust)**

- สถานการณ์ 1 (โอกาส 35%): PCE ตามคาด/ต่ำกว่าคาด หุ้นเทคสหรัฐฯ เด้ง SET กลับขึ้นมาแถว 1,440–1,450 พรุ่งนี้
- สถานการณ์ 2 (โอกาส 45%): ตัวเลขผสม ตลาดสหรัฐฯ แกว่งก่อนวันหยุด SET ทรงตัวต่ำกว่า 1,440 ระหว่างรอรายละเอียดภาษี
- สถานการณ์ 3 (โอกาส 20%): PCE สูงกว่าคาด + ข่าวภาษีไทยอัตราสูง SET ลงไปทดสอบ 1,400–1,420

**ผลกระทบต่อนักลงทุนไทย**

- วันนี้ไม่ใช่วันที่หุ้นไทยลบเพราะตัวเองแย่ลงทันที แต่เป็นความเสี่ยงนโยบายสหรัฐฯ สองเรื่องที่มาพร้อมกัน ผู้ถือหุ้นพื้นฐานดีที่ไม่ได้พึ่งการส่งออกไปสหรัฐฯ ไม่จำเป็นต้องตัดสินใจขายตามแรงตกใจ
- หุ้นอิเล็กทรอนิกส์ (DELTA) เคลื่อนตาม Nvidia และดัชนีหุ้นชิปสหรัฐฯ แทบรายวัน คืนนี้ดูการเปิดตลาดหุ้นสหรัฐฯ 21:30 น. ก่อนตัดสินใจ
- หุ้นธนาคาร (KBANK) โดนแรงขายตามเงินต่างชาติ ไม่ใช่ข่าวเฉพาะของธนาคาร ส่วนต่างดอกเบี้ยของธนาคารไทยไม่ได้แย่ลงจากข่าววันนี้
- คนที่ลงทุนหุ้นสหรัฐฯ ผ่าน DR หรือกองทุนต่างประเทศ ช่วงบาทอ่อนจะได้ส่วนต่างค่าเงินชดเชยบางส่วน แต่ถ้าบาทกลับแข็งหลัง PCE ต่ำ ผลนี้จะกลับทิศ
