## กลางวันวันศุกร์: SET ฟื้นช่วงเช้า แถว 1,431 จุด บวก 16.70 จุด (+1.18%) หลังปิดเมื่อวานที่จุดต่ำสุดรอบ 52 สัปดาห์ · เอเชียบวกเกือบทุกตลาด Kospi +2.2–2.7% Nikkei +0.7–1.2% · บาทเปิด 34.04 · ทองไทยขึ้น 1,000 บาท ทองแท่งขายออก 58,550 บาท · คืนนี้ตลาดสหรัฐฯ เปิดครึ่งวัน

ตลาดหุ้นไทยช่วงเช้าวันศุกร์พลิกกลับขึ้นมาได้ หลังเมื่อวานปิดที่ 1,414.44 จุด ลบ 14.06 จุด ซึ่งเป็นระดับต่ำสุดของช่วง 52 สัปดาห์ ดัชนีเปิดบวกเล็กน้อยแล้วแกว่งลงไปเกือบเท่าระดับปิดเมื่อวานช่วงสิบโมงครึ่ง ก่อนได้แรงซื้อกลับเข้ามาจนขึ้นไปยืนแถว 1,431 จุดก่อนเที่ยง แรงหนุนหลักมาจากตลาดเอเชียที่ยังรีบาวด์ต่อเนื่องเป็นวันที่สองหลังหุ้นเทคถูกขายหนักต้นสัปดาห์ และตัวเลขส่งออกไทยเดือน ต.ค. ที่ออกมาช่วงสายโตถึง 27.5% แต่แรงขายของนักลงทุนต่างชาติ ข่าว Nvidia ระงับส่งเซิร์ฟเวอร์ AI มาไทย และเงินบาทที่อ่อนแถว 34 บาทต่อดอลลาร์ ยังเป็นเพดานที่ทำให้นักวิเคราะห์ส่วนใหญ่มองว่าเป็นการฟื้นระยะสั้น

หมายเหตุ: ตอนเขียนข่าวนี้ยังไม่มีตัวเลข SET ปิดภาคเช้าทางการจากแหล่งที่ตรวจได้ ตัวเลข SET ด้านล่างเป็นภาพระหว่างวันตามเวลาที่ระบุ

**ปัจจัยที่ขับเคลื่อน**

- **แรงซื้อกลับหลังลงหนัก** — SET ลงมาสามวันติดและปิดเมื่อวานที่จุดต่ำสุดรอบปี นักวิเคราะห์ บล.ทิสโก้ ชี้ว่าตลาดขายมากเกินไปแล้ว (oversold) และมูลค่าหุ้นไม่แพง เมื่อเอเชียบวกยกแผง แรงซื้อหุ้นใหญ่จึงกลับเข้ามา ขณะที่ยอดขายชอร์ตที่สูงผิดปกติทำให้มีแรงซื้อปิดสถานะชอร์ตช่วยดันด้วย
- **ส่งออก ต.ค. ดีกว่าที่ตลาดคาด** — กระทรวงพาณิชย์แถลงช่วงสายว่าส่งออกเดือน ต.ค. มูลค่า 36,859.2 ล้านดอลลาร์ โต 27.5% สูงกว่าที่ตลาดคาดราว 26% (รายละเอียดอยู่ในหัวข้อหุ้นเด่น) ช่วยกลบภาพลบเรื่องภาษีนำเข้าสหรัฐฯ ไปได้บางส่วน
- **ตลาดเอเชียยังรีบาวด์หุ้นชิป** — หลังหุ้น AI ถูกขายหนักต้นสัปดาห์ นักลงทุนเอเชียกลับเข้าซื้อหุ้นหน่วยความจำและหุ้นชิปต่อเป็นวันที่สอง ส่วนเกาหลีใต้มีแรงหนุนเพิ่มจากข่าวรัฐบาลพิจารณาขยายกองทุนพยุงตลาดหุ้น
- **ทองไทยขึ้นแรงจากทองโลกฟื้น** — ทองสปอตฟื้นจากจุดต่ำสุดรอบ 15 เดือน ขณะที่บาทอ่อนแถว 34 บาท ทั้งสองแรงทำให้ราคาทองในประเทศขึ้นรวม 1,000 บาทภายในชั่วโมงแรก
- **Wall Street ยังไม่มีราคาใหม่** — สหรัฐฯ หยุด Thanksgiving เมื่อวาน และคืนนี้เปิดครึ่งวัน (ตลาดหุ้นปิด 13:00 น. เวลานิวยอร์ก หรือ 01:00 น. เวลาไทย) ตลาดเอเชียจึงอ้างอิงได้แค่ฟิวเจอร์สสหรัฐฯ ที่บวกราว 0.5–0.6%

**ผลกระทบเชิงโครงสร้าง**

- **การฟื้นครั้งนี้ยังไม่มีเงินต่างชาติหนุน** — ต่างชาติขายสุทธิสะสมเดือน พ.ย. แล้วเกิน 14,000 ล้านบาท และยังไม่มีสัญญาณกลับทิศ แรงซื้อเช้านี้มาจากการซื้อคืนชอร์ตและนักลงทุนในประเทศเป็นหลัก การฟื้นแบบนี้มักไปได้ไม่ไกลถ้าต่างชาติยังขาย
- **เฟดเป็นเพดานของทั้งบาทและทอง** — ตลาดยังให้โอกาสเฟดขึ้นดอกเบี้ย 0.25% ในการประชุม 8–9 ธ.ค. เกือบ 100% ดอลลาร์จึงแข็ง บาทจึงอ่อน การที่ทองไทยขึ้นแรงวันนี้ส่วนหนึ่งเป็นเพราะบาทอ่อน ไม่ใช่ทองโลกขึ้นอย่างเดียว ตามกรอบสงครามพลังงานที่ใช้อยู่ ทองจะฟื้นยั่งยืนได้ต้องเห็นยีลด์สหรัฐฯ ลงชัดหลายวัน ซึ่งเช้านี้ยีลด์กลับขยับขึ้น
- **ดุลการค้าขาดดุลหนักกดบาท** — ส่งออก ต.ค. โตแรงก็จริง แต่นำเข้าโตเร็วกว่า 53.2% จนขาดดุลการค้า 12,343.7 ล้านดอลลาร์ในเดือนเดียว ดุลแบบนี้ไม่ช่วยให้บาทแข็ง ซึ่งเป็นเหตุผลหนึ่งที่บาทยังยืนแถว 34 บาท

**ความเสี่ยงที่ต้องระวัง**

- ภาพปิดภาคบ่าย: สัปดาห์นี้ SET เคยปิดเช้าบวกแล้วกลับลบตอนบ่ายมาแล้ว (26 พ.ย.) ถ้ามีข่าวใหม่เรื่อง Nvidia หรือภาษีสหรัฐฯ ช่วงบ่าย ดัชนีอาจคืนกำไรได้เร็ว
- คืนนี้ Wall Street เปิดครึ่งวัน สภาพคล่องบาง ราคาอาจแกว่งแรงกว่าปกติ โดยเฉพาะหุ้นชิปที่ Nvidia ยังถูก S&P Global Ratings จับตาอาจลดอันดับเครดิต
- น้ำมันยังเสี่ยงขึ้นจากเหตุโจมตีโรงกลั่นซาอุฯ และทุ่นระเบิดในอ่าวโอมาน ซึ่งตามกรอบสงครามพลังงาน = เงินเฟ้อค้าง = เฟดขึ้นดอกเบี้ยได้ต่อ
- เงินบาทอ่อนเกิน 34 บาท ธนาคารแห่งประเทศไทยระบุว่าพร้อมเข้าดูแลถ้าเคลื่อนไหวผิดปกติ

- ฟื้นต่อ (โอกาส 30%): ต่างชาติลดการขาย Wall Street คืนนี้บวก SET ยืนเหนือ 1,430 จุดได้ถึงต้นสัปดาห์หน้า
- แกว่งในกรอบ (โอกาส 50%): SET แกว่ง 1,400–1,440 จุด ตามกรอบที่โบรกส่วนใหญ่ให้ ต่างชาติยังขายแต่ชะลอลง
- กลับลงทดสอบ 1,400 (โอกาส 20%): มีข่าวลบเพิ่มเรื่องการคุมชิป AI หรือภาษีสหรัฐฯ ต่างชาติเร่งขายต่อ

**ผลกระทบต่อนักลงทุนไทย**

- **SET:** โบรกส่วนใหญ่ให้กรอบวันนี้ 1,400–1,430 จุด แนวต้าน 1,440–1,450 จุด ระดับ 1,431 ตอนก่อนเที่ยงจึงอยู่ใกล้ขอบบนแล้ว การไล่ซื้อตามช่วงบ่ายมีความเสี่ยงมากกว่าการรอดูว่าดัชนีปิดวันเหนือ 1,430 ได้หรือไม่
- **กลยุทธ์ที่โบรกแนะนำวันนี้** เน้นหุ้นในประเทศและหุ้นปันผลสูง เช่น กลุ่มธนาคาร สื่อสาร โรงพยาบาล ค้าปลีก ซึ่งได้รับผลน้อยจากข่าว Nvidia และภาษีสหรัฐฯ
- **DBS** ให้เป้า SET สิ้นปี 2027 ที่ 1,650 จุด (P/E ล่วงหน้า 15.3 เท่า) โดยมองว่าแม้การคุมชิป AI จะกระทบหุ้นศูนย์ข้อมูล แต่การบริโภคในประเทศ งบรัฐ และท่องเที่ยวจะช่วยประคอง
- **BCP:** สถานะโรงกลั่นพระโขนงยังไม่ชัด รายงานหนึ่งระบุว่ารัฐมนตรีพลังงานสั่งหยุดหอกลั่น 1 จาก 4 หอ และให้หน่วยที่ 4 เพิ่มกำลังผลิต ขณะที่บางสำนักรายงานว่าสั่งหยุดทั้งโรง ควรรอคำชี้แจงทางการจากบริษัทก่อนตัดสินใจ
- **ทองคำ:** ทองไทยขึ้นมาแล้ว 1,000 บาทในครึ่งเช้า ผู้ที่ตั้งใจซื้อสะสมอาจแบ่งซื้อเป็นงวดแทนการซื้อครั้งเดียว เพราะราคาวันนี้ขึ้นจากบาทอ่อนด้วย ถ้าบาทแข็งกลับ ราคาทองไทยอาจย่อเร็ว ขณะที่ทองโลกยังมีเพดานจากโอกาสเฟดขึ้นดอกเบี้ย
- **เงินบาท:** ผู้นำเข้าหรือผู้ที่ต้องโอนเงินไปต่างประเทศช่วงสิ้นเดือน ควรทยอยซื้อดอลลาร์เมื่อบาทแข็งกลับใกล้ 33.95 ส่วนผู้ส่งออกได้ประโยชน์จากบาทแถว 34
- **ภาษี:** กำไรจากหุ้นไทยและ DR ในตลาดไทยยังไม่เสียภาษีกำไรจากการขาย ส่วนเงินปันผลหุ้นไทยถูกหัก ณ ที่จ่าย 10% ซึ่งเป็นข้อได้เปรียบของกลยุทธ์หุ้นปันผลสูงช่วงตลาดผันผวน
