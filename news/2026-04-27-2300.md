## Microsoft เสียสิทธิ์ผูกขาด OpenAI — สัญญาใหม่ปลด exclusive license, ตัด revenue share, OpenAI ขายผ่าน AWS + Google ได้แล้ว

Microsoft (MSFT) และ OpenAI ออกประกาศร่วมเช้าวันนี้ (US ET) ปรับโครงสร้างความร่วมมือใหม่ครั้งใหญ่ที่สุดนับจากที่ทั้งสองเป็นพันธมิตรกันมาตั้งแต่ปี 2019 — สาระสำคัญคือ Microsoft จะไม่มีสิทธิ์ผูกขาด (exclusive license) ใน intellectual property (ทรัพย์สินทางปัญญา) ของ OpenAI อีกต่อไป และจะหยุดจ่าย revenue share (ส่วนแบ่งรายได้) ที่เคยจ่ายให้ OpenAI สำหรับสินค้าที่นำมาขายต่อบน Azure

ในทางกลับกัน OpenAI ก็ได้สิทธิ์ที่จะเสนอบริการ AI ของตัวเองผ่าน cloud provider ของคู่แข่ง — Amazon Web Services (AWS) และ Google Cloud — ได้อย่างเสรี ในขณะที่ Microsoft ยังคงเป็น "primary cloud partner" และผลิตภัณฑ์ของ OpenAI จะ "ship first on Azure" (เปิดใช้งานบน Azure ก่อน) ยกเว้นกรณีที่ Microsoft ไม่สามารถหรือไม่ต้องการรองรับ feature นั้น

ราคาหุ้น Microsoft ลดลง 1–3% ในการเทรดเช้าวันนี้ ในขณะที่ Amazon (AMZN) และ Alphabet (GOOGL) ปรับขึ้นเล็กน้อย สะท้อนว่านักลงทุนมอง Microsoft เป็นฝ่ายเสียเปรียบในการเปลี่ยนสัญญาครั้งนี้ — สิทธิ์ผูกขาด OpenAI เคยเป็น moat (สิ่งกีดขวางการแข่งขัน) ที่ใหญ่ที่สุดของ Azure ในการแข่งกับ AWS และ Google Cloud

นี่คือสัญญาณที่ 2 ในวันเดียวกันที่ OpenAI กำลังขยายตัวออกจากวงโคจรของ Microsoft — สัญญาณที่ 1 คือข่าวความร่วมมือกับ Qualcomm + MediaTek + Luxshare ในการพัฒนาชิปสำหรับมือถือ AI ของตัวเอง (ดู batch 22:30 ก่อนหน้า)

**ตัวเลขสำคัญ / ลำดับเหตุการณ์**

- ราคา Microsoft ระหว่างเปิดตลาดวันนี้: -1.0% ถึง -3.0% (ขึ้นกับช่วงเวลาตอน rerun ข่าว)
- เงินที่ Microsoft ลงทุนใน OpenAI สะสมตั้งแต่ปี 2019: เกิน 13,000 ล้านดอลลาร์
- มูลค่าฝ่าย for-profit ของ OpenAI ในกระเป๋า Microsoft: 135,000 ล้านดอลลาร์ (ประมาณ 27% ของ OpenAI หลัง dilute ของ shares ที่จะออกใหม่)
- คำมั่นสัญญาใช้จ่ายบน Azure ของ OpenAI ตามสัญญาเดือน ต.ค. 2025: 250,000 ล้านดอลลาร์
- ดีล OpenAI–Amazon (ก.พ. 2026): AWS ลงทุนสูงสุด 50,000 ล้านดอลลาร์ + ขยายสัญญาเดิม 38,000 ล้านดอลลาร์ ออกไปอีก 100,000 ล้านดอลลาร์ ใน 8 ปี
- Amazon เป็น exclusive third-party cloud distribution provider ของ OpenAI Frontier (แพลตฟอร์ม enterprise ของ OpenAI ที่เปิดตัวเดือนนี้)
- Revenue share ที่ OpenAI ยังจ่ายให้ Microsoft: 20% (ไม่เปลี่ยน) — แต่จะมี cap (จำกัดเพดาน) ในการจ่าย และจะสิ้นสุดในปี 2030
- Revenue share ที่ Microsoft เคยจ่าย OpenAI: หยุดทันทีตั้งแต่วันที่ลงนามสัญญาใหม่
- License ของ Microsoft ต่อ OpenAI IP: ขยายออกไปจนถึงปี 2032
- ก่อนหน้านี้: Financial Times รายงานเดือน มี.ค. ว่า Microsoft กำลังพิจารณาฟ้อง Amazon และ OpenAI กรณีดีล 50,000 ล้านดอลลาร์ที่อาจขัดสัญญาผูกขาด — สัญญาใหม่นี้จึงเป็นการประนีประนอมเพื่อหลีกเลี่ยงการฟ้องกัน
- มี.ค. 2026: Memo ภายใน OpenAI หลุดออกมา ระบุว่าสัญญากับ Microsoft "limited our ability" (จำกัดความสามารถของเรา)

**ปัจจัยที่ขับเคลื่อน**

- OpenAI ต้องการความยืดหยุ่นในการขยายฐานลูกค้า — ลูกค้าระดับ enterprise (องค์กรขนาดใหญ่) จำนวนมากใช้ AWS หรือ Google Cloud อยู่แล้ว และไม่ต้องการย้ายมา Azure เพียงเพื่อใช้ ChatGPT/GPT API
- Amazon เข้ามาเป็นนักลงทุนรายใหญ่อันดับสองของ OpenAI ด้วยดีล 50,000 ล้านดอลลาร์ในเดือน ก.พ. — เพิ่มแรงกดดันให้ OpenAI ต้องเปิด AWS เป็นช่องทางจัดจำหน่ายอย่างเป็นทางการ
- การเข้าซื้อ io ของ Jony Ive (6,400 ล้านดอลลาร์) และความร่วมมือกับ Qualcomm + MediaTek แสดงว่า OpenAI กำลังขยายไปสู่ hardware (อุปกรณ์) ของตัวเอง — ซึ่งเป็นพื้นที่ที่ Microsoft ก็มี Surface, HoloLens, และร่วมมือกับ Qualcomm สำหรับ Copilot+ PC อยู่แล้ว → ความขัดแย้งทางผลประโยชน์
- การ recapitalize (ปรับโครงสร้างทุน) ของ OpenAI ในเดือน ต.ค. 2025 เปลี่ยนเป็น Public Benefit Corporation (PBC) แทน non-profit — ทำให้สามารถระดมทุนเพิ่มจากนักลงทุนหลายรายได้
- Microsoft เริ่มลด dependency (การพึ่งพา) บน OpenAI — ลงทุนใน Mistral (ฝรั่งเศส), Anthropic (ผ่าน Azure), และพัฒนา in-house model ชื่อ MAI

**ผลกระทบเชิงโครงสร้าง**

- Microsoft Azure เสีย competitive moat ที่ใหญ่ที่สุดในการแข่งกับ AWS และ Google Cloud — นักลงทุนต้องประเมินใหม่ว่า Azure จะเติบโตได้เท่าเดิมหรือไม่ในระยะยาว
- AWS (กลุ่ม Amazon) ได้ประโยชน์ทันที — สามารถเสนอ ChatGPT/GPT API บนแพลตฟอร์มของตัวเองได้แล้ว สอดคล้องกับการลงทุน 50,000 ล้านดอลลาร์ที่เพิ่งทำในเดือน ก.พ.
- Google Cloud (Alphabet) ได้ประโยชน์รองลงมา — แต่มีความซ้อนกับ Gemini ของตัวเอง อาจไม่ได้ marketing OpenAI products หนัก
- OpenAI ได้ leverage (อำนาจต่อรอง) เพิ่มขึ้น — ตอนนี้สามารถเลือกได้ว่าจะใช้ใคร ทำให้ราคา cloud ที่จ่ายแต่ละรายลดลง และคุณภาพบริการดีขึ้น
- ในระยะกลาง 1–2 ปี กำไรของ Microsoft จากการ resell OpenAI products จะลดลง — แต่ภาระจ่าย rev share ก็หายไปด้วย ผลสุทธิประมาณการในเชิงตัวเลขยังต้องรอ Q3 earnings ดูชัดเจน
- ความสัมพันธ์ MSFT–OpenAI ยังไม่ขาดทันที — Azure ยังเป็น primary cloud, license ยังถึงปี 2032 — แต่ trajectory ชัดเจนว่าทั้งสองจะแยกกันมากขึ้นในอนาคต

**ความเสี่ยงที่ต้องระวัง**

- Microsoft Q3 earnings (29 เม.ย.) เป็นจุดทดสอบสำคัญ — Guidance ของ Azure จะลดลงไหม และ commentary ของ Satya Nadella เกี่ยวกับ AI strategy หลังเปลี่ยนสัญญานี้
- ถ้า Capital Expenditure (CapEx) ของ Microsoft ในไตรมาสนี้ยังสูงกว่า 25,000 ล้านดอลลาร์ และ Azure growth ลดลง — เสี่ยง re-rating (การปรับลดมูลค่า) ของหุ้น
- การที่ OpenAI ไปจัดจำหน่ายผ่าน AWS อาจทำให้ลูกค้า enterprise ของ Microsoft ที่มี Azure อยู่แล้ว เลือกที่จะ migrate (ย้าย) ไป AWS เพื่อรวบ workload ทุกอย่างไว้ที่เดียว
- Sam Altman ยังมีอำนาจในการเจรจาสัญญาใหม่ครั้งต่อไป — ถ้า OpenAI ทำกำไรได้ดีในปี 2027–2028 อาจขอลด rev share ของ Microsoft ลงอีก
- ความเสี่ยงทางการแข่งขัน Antitrust (ต่อต้านการผูกขาด) — สัญญาเก่าที่ Microsoft ผูกขาด OpenAI เคยถูก FTC สอบสวน, การปลด exclusivity เป็นการตอบสนองล่วงหน้า

## Domino's Pizza Q1 พลาดเป้าทุกตัว — ปรับลด Guidance ทั้งปี, CEO ใช้คำว่า "intensifying macro" ส่งสัญญาณ Consumer Slowdown

Domino's Pizza (DPZ) บริษัทเครือร้านพิซซ่าใหญ่ที่สุดในโลก รายงานผลประกอบการไตรมาส 1 ปี 2026 เช้าวันนี้ — พลาดเป้าทั้ง EPS, Revenue, US Same-Store Sales (ยอดขายที่ร้านเดิมเปิดมาแล้วเกิน 1 ปี), และ International Same-Store Sales — ส่งให้ราคาหุ้นลดลง 9–10% ในการเทรดวันนี้ แตะระดับใกล้ 52-week low (จุดต่ำสุดในรอบ 1 ปี)

ที่สำคัญกว่าตัวเลข Q1 คือบริษัทประกาศ ลด Guidance (เป้าผลประกอบการ) ของยอดขายร้านเดิมทั้งสหรัฐฯ และต่างประเทศจาก "3% growth" เป็น "positive low single digits" (ขึ้นเป็นบวกในระดับเลขเดี่ยวต่ำๆ) สะท้อนการยอมรับว่าสภาพแวดล้อมทาง macro (เศรษฐกิจมหภาค) และการแข่งขันจะกดดันธุรกิจตลอดปีนี้

CEO Russell Weiner ใช้คำว่า "an intensifying macro and competitive environment" (สภาพแวดล้อมทาง macro และการแข่งขันที่ทวีความรุนแรงขึ้น) ในการอธิบายผลประกอบการ — เป็นภาษาที่ตรงไปตรงมาที่สุดจาก CEO บริษัท fast food ใหญ่ในรอบหลายไตรมาส และเป็นสัญญาณที่นักวิเคราะห์มองว่าเป็น early warning (สัญญาณเตือนล่วงหน้า) ของ consumer slowdown (การชะลอตัวของผู้บริโภค) ที่จะกระทบกลุ่มร้านอาหารและค้าปลีกในไตรมาสถัดไป

**ตัวเลขสำคัญ**

- กำไรต่อหุ้น (EPS): 4.13 ดอลลาร์ — ต่ำกว่าคาด 4.28 ดอลลาร์ที่ 3.5%
- รายได้รวม: 1,150.6 ล้านดอลลาร์ — ต่ำกว่าคาด 1,162.95 ล้านดอลลาร์ที่ 1.1%
- รายได้โตเทียบปีก่อน: +3.5% (จาก 1,110 ล้านดอลลาร์ Q1 2025)
- กำไรสุทธิเทียบปีก่อน: -6.6% (จากผลกระทบ pre-tax charge 30 ล้านดอลลาร์ของหุ้น DPC Dash)
- US Same-Store Sales (ยอดขายร้านเดิม สหรัฐฯ): +0.9% — ต่ำกว่าคาด +2.6–2.72%
- International Same-Store Sales: -0.4% (excl. FX) — ต่ำกว่าคาด +0.7%
- เป็นไตรมาสแรกในรอบ 4 ไตรมาส ที่ Domino's พลาด US same-store sales
- ราคาหุ้น premarket: -9.99% ลงไปที่ 341 ดอลลาร์ (52-week low ที่ 346.31)
- ราคาหุ้นระหว่างวัน: ลดลงประมาณ 9–10%
- เปิดร้านใหม่ทั่วโลกใน Q1: 180 สาขา (เพิ่มขึ้น)
- บอร์ดอนุมัติ share repurchase (โครงการซื้อหุ้นคืน) เพิ่ม 1,000 ล้านดอลลาร์ — เพื่อรับมือราคาหุ้นที่ตก
- Guidance ใหม่: US + International Same-Store Sales ทั้งปี 2026 = "positive low single digits" (เดิม 3%)
- DPC Dash (กิจการ Domino's ในจีน): บันทึก pre-tax charge 30 ล้านดอลลาร์ — สะท้อนความเสี่ยงในจีน
- P/E ปัจจุบัน: 20.94 เท่า — ต่ำกว่าค่าเฉลี่ยในอดีต

**ปัจจัยที่ขับเคลื่อน**

- สงคราม Iran ทำให้ราคาน้ำมันแพง → ราคาน้ำมันเบนซินในสหรัฐฯ ขึ้นไปที่ 4.20–4.50 ดอลลาร์ต่อแกลลอน → ผู้บริโภคในกลุ่มรายได้ปานกลาง-ล่างเริ่มลดการใช้จ่ายฟุ่มเฟือยลง
- เงินเฟ้ออาหาร (food inflation) ของสหรัฐฯ ในปี 2026 ยังสูงที่ 4.5–5.0% YoY — ต้นทุนวัตถุดิบ Domino's เพิ่ม margin pressure
- การแข่งขันจาก Pizza Hut, Papa John's, Little Caesars และ chain ภูมิภาค — ใช้ promotion ราคาถูกแย่งลูกค้า
- Delivery fee (ค่าส่ง) ของ DoorDash, Uber Eats เพิ่มขึ้น — ทำให้ราคาเดลิเวอรี่ Domino's ผ่าน 3rd party แพงกว่าราคาในร้าน → consumer เลือกเทคแทน
- จีน (DPC Dash) — เศรษฐกิจอ่อนแอ + การบริโภคในเมืองใหญ่ลดลง → impair value ของหุ้นที่ Domino's ถือใน DPC Dash

**ผลกระทบเชิงโครงสร้าง**

- ตอกย้ำสัญญาณ consumer slowdown ที่เริ่มเห็นใน McDonald's (MCD), Starbucks (SBUX), Chipotle (CMG) ในไตรมาสก่อนๆ — Domino's เคยเป็นหุ้น defensive ที่ทนต่อภาวะถดถอย เพราะ pizza เป็น affordable meal (อาหารราคาเข้าถึงได้) — การที่แม้แต่ Domino's ยังพลาด แสดงว่าผู้บริโภครายได้ต่ำเริ่มลด ordering frequency (ความถี่การสั่ง)
- กลุ่มหุ้นร้านอาหาร quick-service restaurant (QSR) ทั้งกลุ่ม จะถูกประเมินใหม่ — รวมถึง McDonald's, Yum Brands, Restaurant Brands International, Wendy's
- Fed กับการตัดสินใจดอกเบี้ย — ถ้า consumer slowdown รุนแรงขึ้น Fed จะมีเหตุผลมากขึ้นที่จะ cut rate แม้ในภาวะน้ำมันแพง
- ขยับน้ำหนัก rotation จากกลุ่ม consumer discretionary (กลุ่มสินค้า/บริการที่ผู้บริโภคซื้อเพิ่มเมื่อมีรายได้เหลือ) ไปยังกลุ่ม consumer staples (กลุ่มสินค้าจำเป็น) เช่น P&G, Walmart, Costco
- Macro signal สำหรับเศรษฐกิจสหรัฐฯ ครึ่งปีหลัง — Domino's เป็น leading indicator (ตัวชี้วัดล่วงหน้า) ของ consumer health เพราะมี franchise model ทั่วประเทศ

**ความเสี่ยงที่ต้องระวัง**

- ถ้าน้ำมันยังขึ้นต่อ (Goldman Q4 target 90 ดอลลาร์ Brent) — ผู้บริโภคจะลดใช้จ่ายเพิ่มอีก กลุ่ม QSR อาจเห็น same-store sales ติดลบในไตรมาส 2 ทั้งกลุ่ม
- การที่ Domino's เพิ่ม share buyback 1,000 ล้านดอลลาร์ เป็น defensive move (การป้องกันราคาหุ้น) — บริษัทรู้ดีว่าราคาจะลงต่อ ถ้าไม่ทำ buyback
- การปรับ guidance ครั้งนี้อาจไม่ใช่ครั้งสุดท้าย — ถ้าไตรมาส 2 ยังพลาด ต้องลด guidance อีกรอบในเดือน ก.ค.
- Margin pressure: cost of food, labor, delivery — ทุกตัวขึ้นพร้อมกัน ในขณะที่ราคา pizza ขึ้นไม่ได้เท่าเพราะการแข่งขัน
- DPC Dash (จีน) — ความเสี่ยงเพิ่ม impairment ในไตรมาสถัดไป

**สำหรับนักลงทุนไทย**

ผลกระทบต่อหุ้นไทยกลุ่มร้านอาหารและค้าปลีก:
- CPALL (7-Eleven ไทย, makro): ถ้าผู้บริโภคไทยเริ่มลดใช้จ่ายตาม pattern ของสหรัฐฯ — ระยะ 6 เดือน อาจเห็น Same-Store Sales (SSSG) ของ 7-Eleven ลดลง
- MAKRO, BJC: ค้าปลีก wholesale + consumer goods — ผลกระทบเชิงลบเล็กถึงปานกลาง
- MINT (Minor International — Burger King, Sizzler, The Pizza Company, Swensen's): พิซซ่าและ casual dining คล้ายกับ Domino's — สัญญาณที่ต้องระวัง
- M (Mc Group — แฟชั่น): เป็น discretionary spending ผู้บริโภค — ลดเป็นรายแรกๆ
- AOT (สนามบิน): ท่องเที่ยวลดลงเพราะ consumer spending ลด → กระทบจำนวนผู้โดยสาร
- กลุ่มที่ได้ประโยชน์: BJC, CPF (อาหารแปรรูป) — กรณีที่ผู้บริโภคย้ายจากการกินนอกบ้านมาทำกินในบ้าน

ช่องทางลงทุนสำหรับนักลงทุนไทย:
- DR ในตลาดไทย: MCD80X (McDonald's) — ตัวแทนกลุ่ม QSR US ที่ defensive กว่า DPZ
- ETF บนตลาดสหรัฐฯ: XLY (Consumer Discretionary), XLP (Consumer Staples) — เปรียบเทียบกัน
- กองทุน FIF: KT-CONSUM, SCBSEMI (กลุ่ม consumer)
- หุ้นไทย defensive: BJC, CPALL — แต่ยังต้องระวังเรื่อง macro

ภาษีที่ต้องระวัง:
- DR ในตลาดไทย: ไม่ต้องเสีย Capital Gains Tax — เงินปันผลถูกหักที่ต้นทาง
- ถือ DPZ ตรงผ่านโบรกต่างประเทศ: Withholding Tax 30% — ลดเหลือ 15% ด้วย W-8BEN
- DPZ ไม่จ่ายเงินปันผลเป็นกอบเป็นกำ — Yield ต่ำ (1.7%) — ลงทุนเพื่อ growth ไม่ใช่ income

ประเมินสถานการณ์:
- กรณีดี (25%): Iran hostilities คลี่คลาย → น้ำมันลง → consumer ฟื้น → DPZ Q2 ดีขึ้น → ราคาฟื้น 5–8%
- กรณีฐาน (55%): Macro ยังกดดันต่อเนื่อง → DPZ ทรงตัว 340–360 ดอลลาร์ → รอดูไตรมาส 2 (ก.ค.)
- กรณีร้าย (20%): Macro แย่ลง + Q2 พลาดอีก → DPZ ลงไปที่ 300–320 ดอลลาร์ → P/E กดถึง 18–19 เท่า

ผลกระทบต่อ asset allocation พอร์ตไทย:
- ลด overweight กลุ่ม consumer discretionary ทั้งไทยและต่างประเทศ
