## Akamai (AKAM) พุ่ง 27% — ดีลคลาวด์ 1,800 ล้านดอลลาร์กับ Anthropic ใหญ่ที่สุดในประวัติศาสตร์บริษัท · พลิกโฉมจาก CDN เก่าสู่ผู้ให้บริการ AI Infrastructure

หุ้น Akamai Technologies (AKAM) พุ่งขึ้น 27% ในวันที่ 8 พ.ค. 2026 ปิดที่ 148.38 ดอลลาร์ — ระดับสูงสุดในรอบ 5 ปี — หลัง Bloomberg เปิดเผยว่าคู่สัญญารายใหญ่ที่บริษัทประกาศไว้ในวันก่อนหน้าโดยใช้คำว่า "leading frontier model provider" คือ **Anthropic** ผู้พัฒนา AI โมเดล Claude โดยเป็นสัญญาคลาวด์ระยะ 7 ปี มูลค่า **1,800 ล้านดอลลาร์** ซึ่งเป็นดีลใหญ่ที่สุดในประวัติศาสตร์ของ Akamai

ความน่าสนใจคือ Akamai ที่หลายคนรู้จักในฐานะผู้ให้บริการ CDN (Content Delivery Network — เครือข่ายส่งผ่านเนื้อหาเว็บ) แบบเก่าในยุค Yahoo / Netflix รุ่นแรก กำลังพลิกโฉมเป็น **Tier-2 AI Infrastructure Provider** ที่สามารถดึงลูกค้าระดับเดียวกับ AWS, Google Cloud, Microsoft Azure ได้แล้ว — และนี่คือดีลแรกที่ขนาดใหญ่พอจะเปลี่ยนภาพลักษณ์ของบริษัทอย่างถาวร

**Akamai ทำธุรกิจอะไร — เข้าใจให้ชัดก่อนวิเคราะห์**

Akamai เริ่มต้นในปี 1998 ในฐานะผู้บุกเบิกเทคโนโลยี CDN — ระบบเก็บไฟล์เว็บไซต์ (รูป วิดีโอ ข้อความ) ไว้ที่เซิร์ฟเวอร์กระจายทั่วโลก เพื่อให้ผู้ใช้ปลายทางเปิดเว็บได้เร็วขึ้น เพราะดึงข้อมูลจากเซิร์ฟเวอร์ใกล้ตัว ไม่ต้องวิ่งข้ามทวีปไปดึงจากเซิร์ฟเวอร์ต้นทาง

ปัจจุบันธุรกิจของ Akamai แบ่งเป็น 3 ขา:

- **Content Delivery (เครือข่ายส่งผ่านเนื้อหา)** — ธุรกิจดั้งเดิม รายได้ลดลงทุกปีเพราะคู่แข่งเช่น Cloudflare บีบราคา
- **Security (ความปลอดภัยทางไซเบอร์)** — ธุรกิจ Web Application Firewall, DDoS Protection, Bot Management โตประมาณ 11% ต่อปี
- **Cloud Infrastructure Services / CIS (บริการโครงสร้างคลาวด์)** — ธุรกิจใหม่ที่เกิดจากการซื้อกิจการ **Linode** ในปี 2022 มูลค่า 900 ล้านดอลลาร์ + ลงทุนเพิ่มอีกหลายพันล้านในการกระจายเซิร์ฟเวอร์ GPU ไปทั่วโลก

**ความได้เปรียบเฉพาะของ Akamai ในเวที AI Cloud**

แทนที่จะแข่งกับ AWS / Azure / Google Cloud ในตลาดศูนย์ข้อมูลใหญ่ (Hyperscale Data Center) ที่ตัวเองสู้ไม่ได้ — Akamai เลือก **เล่นเกม Edge Inference** (การประมวลผล AI ที่ปลายขอบเครือข่าย ใกล้กับผู้ใช้)

- มีเซิร์ฟเวอร์กระจายมากกว่า **4,400 จุด** ทั่วโลก (มากกว่า AWS / Azure / GCP ของ 3 รายรวมกัน)
- ติดตั้ง GPU ของ NVIDIA Blackwell RTX PRO 6000 Server Edition ทั่วเครือข่ายเดิม
- เคลมลด Latency (ความล่าช้า) ได้ถึง 60% และต้นทุนต่ำกว่า Hyperscaler ถึง 86% สำหรับงาน Inference (การให้ AI ตอบกลับผู้ใช้)
- เหมาะกับงาน AI Agent, ระบบขับเคลื่อนอัตโนมัติ, ระบบสุขภาพ, การตรวจจับการฉ้อโกงทางการเงิน — ที่ความเร็วในระดับ millisecond (มิลลิวินาที) สำคัญมากกว่าขนาดของโมเดล

**ตัวเลขสำคัญจากดีล Anthropic + งบไตรมาสแรก ปี 2026**

- **มูลค่าดีล Anthropic = 1,800 ล้านดอลลาร์** ระยะเวลา 7 ปี — ใหญ่ที่สุดในประวัติศาสตร์ Akamai
- **รายได้จากดีลเริ่มเข้าไตรมาส 4 ปี 2026** ประมาณ 20-25 ล้านดอลลาร์ในไตรมาสแรกของสัญญา
- **คิดเป็น Run Rate (อัตรารายเดือนเฉลี่ย)** ประมาณ 21 ล้านดอลลาร์ต่อเดือน หรือ 257 ล้านดอลลาร์ต่อปีเมื่อเต็มที่ — เทียบกับรายได้รวมปัจจุบันประมาณ 4,400 ล้านดอลลาร์ต่อปี = ประมาณ 6% ของรายได้ทั้งหมด
- **รายได้ไตรมาสแรก 2026 = 1,074 ล้านดอลลาร์** — เกินคาดเล็กน้อย โตจากปีก่อน 6%
- **EPS (กำไรต่อหุ้น) ปรับ = 1.61 ดอลลาร์** — ตรงตามที่นักวิเคราะห์คาด แต่ลดลงจาก 1.70 ดอลลาร์ในปีก่อน
- **Cloud Infrastructure Services (CIS) โต 40% YoY** — เป็นเครื่องยนต์การเติบโตหลัก
- **Security โต 11% YoY** — โตช้ากว่าที่ตลาดคาด
- **CDN เก่า ติดลบประมาณ 5%** — ตามคาดของแนวโน้มขาลงระยะยาว
- **เป้ารายได้ทั้งปี 2026** = 4,445-4,550 ล้านดอลลาร์ (ปรับขึ้นจากเป้าเดิม)
- **เป้า EPS ทั้งปี = 6.40-7.15 ดอลลาร์** — ต่ำกว่าที่นักวิเคราะห์คาด (6.86 ดอลลาร์) เพราะลงทุน CapEx (เงินลงทุน) สูงในการขยาย GPU

- **7 พ.ค. 2026 (ก่อนงบ)** ปิดที่ 116.69 ดอลลาร์ (+31% ในเดือน — เริ่มมีข่าวลือ)

**ปัจจัยที่ขับเคลื่อน**

1. **Anthropic ต้องการ Compute เพิ่มแบบเร่งด่วน** — Dario Amodei ซีอีโอ Anthropic บอกในงาน "Code with Claude" ว่ารายได้และการใช้งานโต **80 เท่า** ในไตรมาสแรกปี 2026 ทำให้ต้องหาผู้ให้บริการคลาวด์เพิ่มจาก Google Cloud (สัญญา 200,000 ล้านดอลลาร์, 5 ปี) และ SpaceX (ชิป + คลาวด์) — Akamai คือรายที่ 3 ที่เซ็นได้

2. **ตลาด AI Compute ขาดแคลนอย่างหนัก** — แม้แต่ Hyperscaler ใหญ่ๆ ก็ไม่สามารถซัพพลาย GPU ให้ลูกค้า Tier 1 ทันได้ — เปิดช่องให้ผู้ให้บริการอย่าง Akamai ที่มีโครงข่ายกระจายมาก่อนแล้วได้ประโยชน์

3. **Edge Inference เป็นเทรนด์ใหม่ของ AI** — เมื่อโมเดลเริ่มเป็น Agent (ทำงานตอบโต้แบบเรียลไทม์) แทนที่จะแค่ตอบคำถาม → ความเร็วของ Latency สำคัญกว่าขนาดโมเดล → Akamai มีข้อได้เปรียบจาก 4,400 จุดทั่วโลก

4. **KeyBanc ปรับเป้าราคาขึ้นเป็น 195 ดอลลาร์** จาก 120 ดอลลาร์ (Overweight) — เป็นสัญญาณว่านักวิเคราะห์เริ่มมอง Akamai เป็นบริษัท AI infrastructure จริงๆ ไม่ใช่บริษัท CDN เก่าๆ

**ผลกระทบเชิงโครงสร้าง**

- **กลุ่มผู้ให้บริการคลาวด์ระดับ Tier-2** (เช่น CoreWeave, Lambda Labs, Crusoe) ได้แรงสนับสนุนทางความเชื่อมั่น — Anthropic ยอมเซ็นกับผู้ให้บริการนอก Hyperscale = ตลาดเปิดกว้างขึ้น
- **NVIDIA (NVDA)** ได้ประโยชน์ทางอ้อม — ทุกดีลคลาวด์ AI ขนาดนี้ต้องการ GPU Blackwell หลายพันตัว
- **Anthropic** กำลังกระจายความเสี่ยงจากการพึ่งพา Google Cloud เพียงรายเดียว — เป็นกลยุทธ์ Multi-Cloud ที่ลูกค้า Enterprise ทุกรายต้องทำ
- **AWS / Azure** อาจมองเป็นสัญญาณเตือนว่า Hyperscale ไม่ได้กินขนมเค้กทั้งก้อนของ AI Compute อีกต่อไป

**ความเสี่ยงที่ต้องระวัง**

1. **กระจุกตัวกับลูกค้าเดียว** — ดีล 1,800 ล้านดอลลาร์ที่กระจายเป็น 257 ล้านดอลลาร์ต่อปี = ลูกค้าใหญ่ที่สุดของ Akamai — ถ้า Anthropic เปลี่ยนผู้ให้บริการในอนาคต หรือมีปัญหาทางธุรกิจ Akamai จะกระทบหนัก

2. **Forward P/E (อัตราส่วนราคาต่อกำไรล่วงหน้า) สูงถึง 31 เท่า** — เทียบกับค่าเฉลี่ยกลุ่ม IT ที่ 12 เท่า = ราคาเข้ามาเก็งล่วงหน้าค่อนข้างสูง

3. **Q2 ปี 2026 EPS Guidance อ่อน** — บริษัทคาด EPS ไตรมาส 2 อยู่ที่ 1.45-1.65 ดอลลาร์ ซึ่งต่ำกว่า Consensus เพราะต้องเร่งลงทุน CapEx ในการขยาย GPU

4. **ธุรกิจ CDN เก่าหดตัวต่อเนื่อง** — รายได้ลดลงประมาณ 5% ต่อปี แม้จะถูกชดเชยด้วย Cloud / Security แต่ก็เป็นแรงต้านโครงสร้าง

5. **Hyperscaler ลงทุนหนักใน Edge เช่นกัน** — AWS Wavelength, Google Distributed Cloud, Microsoft Azure Edge Zones กำลังพยายามเล่นเกมเดียวกัน — Akamai ต้องวิ่งเร็วเพื่อไม่ให้ตามทัน

6. **ราคาหุ้น +67% ใน 1 เดือน** — มีโอกาสเจอ Sell on News (ขายเมื่อข่าวออก) จากนักลงทุนระยะสั้นที่เก็งกำไรไว้ก่อน

**3 สถานการณ์ที่อาจเกิด (ประเมินจาก JP Trust Learning)**

- **Bull Case (โอกาส 35%):** ดีล Anthropic เป็นเพียงดีลแรกของยุคใหม่ — Akamai ดึงลูกค้า AI ระดับใหญ่อีก 2-3 รายใน 12 เดือนข้างหน้า → CIS เร่งโตเป็น 50%+ → EPS ปี 2027 แตะ 9-10 ดอลลาร์ → ราคาหุ้นไป 200-220 ดอลลาร์ (KeyBanc บวก)

- **Base Case (โอกาส 50%):** ดีล Anthropic เกิดจริงตามเป้า → CIS โต 35-40% ต่อปี → EPS ปี 2027 อยู่ที่ 7-8 ดอลลาร์ → ราคาหุ้นเข้าสู่ช่วง 130-160 ดอลลาร์ — สอดคล้องกับเป้านักวิเคราะห์โดยเฉลี่ย

- **Bear Case (โอกาส 15%):** Anthropic เลื่อนการเริ่มต้นรับบริการ หรือลดขนาด → Q4 ปี 2026 รายได้ต่ำกว่าเป้า → ราคาเก็งกำไรไว้สูงเกิน 31 เท่า PE จะถูกปรับลง → ราคาหุ้นกลับลงไปที่ 95-110 ดอลลาร์

**สำหรับนักลงทุนไทย**

- **AKAM ไม่มีในรูปแบบ DR (Depositary Receipt — ใบรับฝากหุ้นต่างประเทศ) บนตลาดไทย** — ต้องลงทุนผ่านโบรกเกอร์ต่างประเทศ (Interactive Brokers, eToro) หรือกองทุน FIF (Foreign Investment Fund — กองทุนรวมลงทุนต่างประเทศ) ที่เน้นกลุ่ม Software / Cloud
- **ภาษีหัก ณ ที่จ่ายเงินปันผล 30%** บนปันผลหุ้นสหรัฐฯ ลดเหลือ 15% ด้วยการกรอกแบบ W-8BEN — แต่ AKAM ไม่จ่ายปันผลอยู่แล้ว ดังนั้นไม่มีประเด็นนี้
- **กำไรจากการขายหุ้น 15%** เมื่อนำเงินกลับเข้าไทย (กฎหมายภาษีใหม่ ม.ค. 2024) — เป็นต้นทุนที่ต้องคำนวณก่อนเข้าซื้อ
- **เปรียบเทียบกับ NVDA80X (DR ของ NVIDIA บนตลาดไทย):** ถ้านักลงทุนไทยอยากเล่นธีม AI Infrastructure แต่ไม่อยากเสียภาษี Capital Gains — NVDA80X เป็นทางเลือกที่ตรงกว่า เพราะ NVDA เป็นผู้ขาย GPU ให้กับ Akamai โดยตรง = ได้ประโยชน์ทุกครั้งที่ Akamai ขยายเครือข่าย
- **หุ้นไทยที่เกาะธีม AI Hardware:** DELTA, KCE, HANA — กลุ่ม Electronics ที่ผลิตชิ้นส่วน PCB / Power Supply / Sensor ให้กับ Data Center ทั่วโลก ได้ประโยชน์จากกระแส AI Capex ของ Akamai และ Hyperscaler ทั้งกลุ่ม
- **กองทุน FIF ที่มี AKAM ในพอร์ต:** กองทุน Global Technology / Cloud Computing Theme เช่น KT-CLOUD, B-INNOTECH — มี Akamai ถือเป็นองค์ประกอบรอง (น้ำหนัก 0.5-2%) — ไม่ใช่ทางเลือกที่ตรงเป้าหากต้องการ Pure Akamai exposure
- **ความเสี่ยงค่าเงิน:** ดอลลาร์แข็งจากปัญหา Iran (ดอกเบี้ยสูง) → เงินบาทอ่อน → ต้นทุนเข้าซื้อหุ้นสหรัฐฯ สูงขึ้นเทียบกับเดือน ก.พ. ที่ผ่านมา ประมาณ 4-5%
- **กลยุทธ์ position sizing สำหรับนักลงทุนไทย:** เนื่องจากราคาขึ้น 67% ใน 1 เดือน + Forward PE 31 เท่า — ถ้าสนใจเข้าซื้อ ควรแบ่งเข้าหลายไม้ (ไม่กระโดดเข้าหมดทีเดียว) และจำกัดน้ำหนักไม่เกิน 2-3% ของพอร์ต เนื่องจากความผันผวนสูง
