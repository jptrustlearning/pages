## เย็นวันพฤหัสบดี: SET ปิดเช้า 1,461.81 จุด ลบ 10.20 จุด BH ลบ 6.74% นำมูลค่าซื้อขาย · เอเชียปิดผสม Hang Seng −1.95% แต่ Kospi +1.39% Nikkei +0.71% · ยุโรปเปิดบวก Stoxx 600 +0.3% หุ้นชิปนำ · ฟิวเจอร์ส Nasdaq 100 บวกราว 1.8% S&P 500 ราว 1% ก่อน Anthropic เข้าซื้อขายคืนนี้ · 20:30 น. ตัวเลขขอรับสวัสดิการว่างงานและดัชนีภาคการผลิตฟิลาเดลเฟีย · Walmart ประกาศงบก่อนตลาดเปิด

ภาพตลาดช่วงเย็นวันพฤหัสบดีแยกเป็นสองฝั่งชัดเจน ฝั่งเอเชียยังถูกกดดันจากบันทึกการประชุมเฟดที่ส่งสัญญาณขึ้นดอกเบี้ยต่อ หุ้นไทยลบตลอดช่วงเช้า และฮ่องกงลบเกือบ 2% ขณะที่ฝั่งตะวันตกเริ่มหันกลับมาซื้อหุ้นเทคโนโลยี เพราะราคาเสนอขายหุ้น IPO ของ Anthropic ที่ 83 ดอลลาร์ สูงกว่าช่วงที่ตั้งไว้ ถูกตีความว่าความต้องการลงทุนในธีมปัญญาประดิษฐ์ยังแข็งแรง แม้ดอกเบี้ยจะสูง

ตลาดฟิวเจอร์สสหรัฐฯ จึงชี้ว่าคืนนี้ Nasdaq อาจเปิดบวกแรงที่สุดในรอบหลายวัน หลัง S&P 500 ลบติดต่อกันมาห้าวัน แต่คืนนี้ยังมีตัวเลขเศรษฐกิจสองชุดที่ออกพร้อมกันตอน 20:30 น. เวลาไทย และงบ Walmart ที่เป็นภาพสะท้อนการใช้จ่ายของผู้บริโภคสหรัฐฯ ก่อนเทศกาลวันหยุดปลายปี ถ้าตัวเลขแรงงานออกมาแข็งกว่าคาด แรงซื้อหุ้นเทคโนโลยีจากเรื่อง Anthropic อาจถูกหักล้างด้วยความกังวลว่าเฟดต้องขึ้นดอกเบี้ยแรงกว่าเดิม

**ปัจจัยที่ขับเคลื่อน**

- **สองแรงที่ดึงตลาดคนละทาง:** แรงแรกคือดอกเบี้ย บันทึกการประชุมเฟดที่ระบุว่ากรรมการเกือบทุกคนเห็นว่าต้องขึ้นดอกเบี้ยต่อ และความเห็นของ Christopher Waller ที่เสนอว่าเฟดอาจต้องขึ้น 0.50% หรือให้แนวทางขึ้นดอกเบี้ยต่อในปี 2027 อย่างชัดเจน แรงที่สองคือหุ้นปัญญาประดิษฐ์ที่ได้แรงหนุนจาก Anthropic ซึ่งระดมทุนได้ราว 81,300 ล้านดอลลาร์ มูลค่าบริษัทราว 1.5 ล้านล้านดอลลาร์ ตลาดเอเชียช่วงกลางวันสะท้อนแรงแรกมากกว่า ส่วนยุโรปและฟิวเจอร์สสหรัฐฯ ช่วงเย็นสะท้อนแรงที่สองมากกว่า
- **เอเชียแยกตามโครงสร้างตลาด:** Kospi ซึ่งมีน้ำหนักหุ้นชิปหน่วยความจำสูง ได้ประโยชน์จากการกลับมาซื้อหุ้นเทคโนโลยี ส่วน Hang Seng ยังถูกฉุดจากงบ Tencent ที่ต่ำกว่าคาด และ SET ซึ่งแทบไม่มีหุ้นปัญญาประดิษฐ์ขนาดใหญ่ ได้แต่ผลด้านลบจากดอลลาร์แข็ง
- **หุ้นโรงพยาบาลเป็นตัวถ่วงหลักของ SET วันนี้:** BH ลบวันที่สองติดต่อกันหลังผู้บริหารมองรายได้ไตรมาส 4 ทรงตัว และ BDMS ลบตาม หุ้นกลุ่มที่เคยถูกใช้เป็นที่หลบภัยกลับกลายเป็นแหล่งแรงขาย
- **ทองคำยังไม่ฟื้น แม้ดอลลาร์อ่อนลงเล็กน้อย:** ราคาทองยังทรงตัวใกล้ระดับต่ำสุดในรอบราวหนึ่งปี เพราะตลาดยังเชื่อเกือบเต็มว่าเฟดจะขึ้นดอกเบี้ยใน ธ.ค. ทองซึ่งไม่มีดอกเบี้ยจึงยังเสียเปรียบ

**ผลกระทบเชิงโครงสร้าง**

- **ตลาดสหรัฐฯ เริ่มแยกหุ้นเทคโนโลยีออกจากตลาดโดยรวม:** เมื่อวาน Nasdaq บวกแต่ Dow ลบกว่า 500 จุด และคืนนี้ฟิวเจอร์ส Nasdaq 100 บวกเกือบสองเท่าของ Dow แปลว่าเงินกำลังกระจุกในหุ้นที่มีเรื่องปัญญาประดิษฐ์รองรับ ขณะที่หุ้นที่ไวต่อดอกเบี้ยถูกปล่อยทิ้ง
- **ตลาดหุ้นไทยไม่ได้ประโยชน์จากธีมนี้โดยตรง:** หุ้นอิเล็กทรอนิกส์อย่าง DELTA ยังลบในวันที่ยุโรปและฟิวเจอร์สสหรัฐฯ หันมาซื้อหุ้นชิป สะท้อนว่าแรงขายจากต่างชาติเพราะค่าเงินและดอกเบี้ยยังมีน้ำหนักมากกว่า
- **ตัวเลขแรงงานคืนนี้มีน้ำหนักต่อกรอบการขึ้นดอกเบี้ย:** ถ้าผู้ขอรับสวัสดิการว่างงานยังต่ำราว 200,000 ราย ตลาดจะยิ่งมั่นใจว่าตลาดแรงงานแน่นพอให้เฟดขึ้นต่อ ซึ่งเป็นแรงกดดันต่อทองและพันธบัตร

**ความเสี่ยงที่ต้องระวัง**

- การเปิดซื้อขายของ Anthropic เป็นปัจจัยที่ตลาดคาดหวังไว้สูงแล้ว ถ้าราคาซื้อขายวันแรกต่ำกว่าคาด แรงบวกของฟิวเจอร์สคืนนี้อาจกลับทิศได้เร็ว
- ตัวเลขฟิลาเดลเฟียที่ตลาดคาดสูงถึง 23.2 ถ้าออกมาแข็งกว่าคาด อาจดันยีลด์กลับขึ้นเหนือ 5.1%
- Jefferson พูดช่วงดึก ถ้าท่าทีใกล้เคียง Waller ตลาดอาจเพิ่มน้ำหนักการขึ้น 0.50% ใน ธ.ค.
- SET ยังไม่สามารถยืนเหนือแนว 1,465–1,470 จุดได้ ถ้าคืนนี้ตลาดสหรัฐฯ ไม่ช่วย พรุ่งนี้อาจทดสอบ 1,450 จุด

**สามสถานการณ์คืนนี้ (JP Trust ประเมินเอง)**

- สถานการณ์ 1 (โอกาส 45%): Anthropic เปิดซื้อขายสูงกว่าราคาเสนอขาย และตัวเลขแรงงานใกล้คาด Nasdaq ปิดบวก ยุติการลบติดต่อกันของ S&P 500 SET พรุ่งนี้มีโอกาสดีดกลับเหนือ 1,465 จุด
- สถานการณ์ 2 (โอกาส 35%): หุ้นเทคโนโลยีบวกช่วงแรกแต่ถูกขายทำกำไรระหว่างวัน ตลาดปิดผสม SET พรุ่งนี้แกว่งในกรอบ 1,450–1,470 จุด
- สถานการณ์ 3 (โอกาส 20%): ตัวเลขแรงงานและฟิลาเดลเฟียแข็งกว่าคาดมาก หรือ Anthropic ซื้อขายต่ำกว่าราคาเสนอขาย ยีลด์ขึ้น ดอลลาร์แข็ง SET พรุ่งนี้มีความเสี่ยงหลุด 1,450 จุด

**ผลกระทบต่อนักลงทุนไทย**

- **หุ้นไทย:** กรอบสั้นยังเป็นการแกว่งตัวใต้แนว 1,470 จุด นักวิเคราะห์ส่วนใหญ่แนะนำเลือกหุ้นรายตัวแทนการไล่ราคา บล.เอเชีย พลัส เลือกหุ้นที่ได้ประโยชน์จากบาทอ่อนและภาคท่องเที่ยว ขณะที่ FSS แนะนำทยอยเข้ากลุ่มหุ้นปันผลโดยเฉพาะโรงไฟฟ้าที่ลดลงมามาก
- **กลุ่มโรงพยาบาล:** BH และ BDMS ถูกขายต่อเนื่องจากแนวโน้มไตรมาส 4 ที่ไม่เติบโต ควรรอให้ราคาหยุดลงก่อนพิจารณา ไม่ควรเข้าซื้อเพียงเพราะราคาลดลงมาก
- **หุ้นอิเล็กทรอนิกส์:** DELTA ยังไม่ตอบสนองต่อการฟื้นของหุ้นชิปในต่างประเทศ ถ้าคืนนี้หุ้นชิปสหรัฐฯ บวกจริงต่อเนื่องถึงตลาดปิด พรุ่งนี้อาจเห็นแรงซื้อกลับ แต่ยังต้องระวังแรงขายจากต่างชาติ
- **หุ้นเทคโนโลยีสหรัฐฯ ผ่าน DR และกองทุน FIF:** ผู้ที่ถือ DR ของ Nvidia หรือกองทุนหุ้นเทคโนโลยีสหรัฐฯ ได้แรงหนุนสองชั้นถ้าหุ้นขึ้นพร้อมบาทอ่อน เพราะผลตอบแทนเมื่อแปลงกลับเป็นบาทสูงขึ้น แต่ความเสี่ยงก็สองชั้นเช่นกันถ้าบาทกลับแข็ง
- **การซื้อ Anthropic วันแรก:** หุ้น IPO ขนาดใหญ่มักแกว่งแรงในวันแรก ผู้ที่ซื้อผ่านโบรกเกอร์ต่างประเทศควรตั้งราคาจำกัด ไม่ใช้คำสั่งซื้อตามราคาตลาด และคำนึงว่ากำไรจากการขายหุ้นต่างประเทศต้องเสียภาษีเมื่อนำเงินกลับเข้าไทยตามกฎที่ใช้ตั้งแต่ ม.ค. 2024
- **ทองคำ:** ทองในประเทศยังเคลื่อนไหวตามทองโลกหักด้วยผลของบาทอ่อน ผู้ที่ทยอยสะสมควรแบ่งไม้ซื้อหลายครั้ง เพราะตัวตัดสินทิศทางระยะถัดไปคือการประชุมเฟด 8–9 ธ.ค.
- **เงินบาท:** ดอลลาร์อ่อนลงเล็กน้อยช่วงเย็น แต่ตราบใดที่ตลาดยังมองว่าเฟดขึ้นดอกเบี้ย บาทยังมีแนวโน้มอ่อนใกล้ 34 บาทต่อดอลลาร์ ผู้นำเข้าควรพิจารณาป้องกันความเสี่ยงค่าเงิน
