## ทำไม MU ถึงขึ้นไม่หยุด — Memory Supercycle จาก AI Demand ที่ HBM ขายหมดถึงปี 2027

หุ้น Micron Technology ($MU) ปรับตัวขึ้นต่อเนื่องเป็นหนึ่งในหุ้น Semiconductor ที่ร้อนแรงที่สุดของปี 2026 ด้วยการ rally ราว 74-77% ตั้งแต่ต้นปี และเฉพาะเดือนเมษายนเดือนเดียวพุ่งราว 41-47% ซึ่งเป็นเดือนเมษายนที่ดีที่สุดนับตั้งแต่ปี 2001 ราคาปิดล่าสุดอยู่ในกรอบ $480-525 หลังแตะจุดสูงสุดตลอดกาลที่ $531

เหตุผลที่ราคา **ขึ้นแล้วยังขึ้นต่อ** ไม่ใช่เรื่องเก็งกำไรชั่วคราว แต่เป็น **โครงสร้างอุปสงค์-อุปทาน (Supply-Demand)** ที่เปลี่ยนไปอย่างถาวรจาก AI Boom — ลูกค้าจองสินค้าหมดล่วงหน้าหลายปี และวอลล์สตรีทเริ่มประเมินใหม่ว่าธุรกิจ Memory ที่เคยเป็น cyclical (มีรอบขึ้น-ลงรุนแรง) อาจกำลังเข้าสู่วัฏจักรที่ยาวกว่าปกติ

**ตัวเลขสำคัญ**

- Q1 FY2026 (ไตรมาสล่าสุด): รายได้ $13.64 พันล้านดอลลาร์ เติบโต 57% YoY (เทียบช่วงเดียวกันปีก่อน)
- EPS (กำไรต่อหุ้น) Non-GAAP $4.78 ทะลุประมาณการนักวิเคราะห์ที่ $3.94
- Cloud Memory Business Unit (กลุ่ม HBM สำหรับ AI Server): รายได้ $5.28 พันล้านดอลลาร์ เกือบเท่าตัวเทียบปีก่อน
- Gross Margin (อัตรากำไรขั้นต้น) ของกลุ่มนี้: 66% และ Operating Margin 55%
- Guidance Q2: รายได้ $18.7 พันล้านดอลลาร์ EPS $8.42 Gross Margin ราว 68%
- ราคาหุ้นย้อนหลัง 1 ปี: บวก 532% ย้อน 3 ปี: บวก 714%

**ปัจจัยที่ขับเคลื่อน — 4 เสาหลัก**

**1) HBM ขายหมดทั้งปี 2026 ภายใต้สัญญาผูกพัน**

HBM (High-Bandwidth Memory คือ หน่วยความจำความเร็วสูงพิเศษที่ใช้ในการ์ด AI ของ NVIDIA และ AMD) ของ Micron ทั้งปี 2026 ถูกจองหมดล่วงหน้าภายใต้สัญญา Long-Term Agreement (สัญญาซื้อขายระยะยาว) — ไม่ใช่แค่จองหลวมๆ แต่เป็นสัญญาผูกพันที่กำหนดทั้งปริมาณและราคา และคำสั่งซื้อยืดยาวไปถึงปี 2027

นี่คือการเปลี่ยนแปลงเชิงโครงสร้างจากเดิมที่ Memory Industry (อุตสาหกรรมหน่วยความจำ) เซ็นสัญญาแบบ 1 ปี — Micron เป็นผู้ผลิต HBM รายแรกที่เซ็นสัญญา 5 ปีในเดือนมีนาคม 2026

**2) Hyperscaler Capex (เงินลงทุนของยักษ์ใหญ่ Cloud) ขึ้นเร็วกว่าคาด — และพูดตรงๆ ว่าเป็นเพราะค่า Memory แพง**

- Meta ปรับ Capex ปี 2026 ขึ้นเป็น $125-145 พันล้านดอลลาร์ — Mark Zuckerberg ระบุชัดว่า "ส่วนใหญ่" มาจากต้นทุนชิ้นส่วนที่สูงขึ้น โดยเอ่ยถึง Memory โดยตรง
- Microsoft ตั้ง Capex ปี 2026 ที่ $190 พันล้านดอลลาร์ — CFO Amy Hood ยอมรับว่า $25 พันล้านดอลลาร์ของตัวเลขนี้มาจากค่าชิ้นส่วนที่สูงขึ้น
- Amazon — CEO Andy Jassy พูดตรงๆ ว่า "ต้นทุนชิ้นส่วน โดยเฉพาะ Memory พุ่งขึ้นมาก" และ "กำลังการผลิตไม่พอ" ต่อความต้องการ

คำพูดของ CFO/CEO ระดับนี้คือคำยืนยันที่หนักแน่นที่สุดว่า Pricing Power (อำนาจในการตั้งราคา) อยู่ในมือผู้ผลิตอย่าง Micron จริง

**ผลกระทบเชิงโครงสร้าง**

ตลาด Memory เคยถูกมองเป็นธุรกิจที่ขึ้น-ลงรุนแรงตามวัฏจักร (Boom-and-Bust Cycle) — ราคาขึ้นเมื่อสินค้าขาด ลงเมื่อล้นตลาด แต่ AI กำลังสร้างเงื่อนไขใหม่:

- HBM เป็นสินค้าที่ผลิตยาก กระบวนการ Qualification (การทดสอบรับรอง) กับลูกค้าใช้เวลานาน — ผู้ผลิตใหม่เข้ามายาก
- การที่ผู้ผลิต HBM 3 ราย (Micron + SK Hynix + Samsung) ขายหมดทั้งปีพร้อมกัน หมายถึง Demand เกิน Supply ทั้งอุตสาหกรรม ไม่ใช่แค่ Micron
- TD Cowen ประเมินว่าสัญญา LTA ใหม่กำหนด Gross Margin ขั้นต่ำ 60% เพดาน 80%+ — ป้องกันการล่วงไหลของราคาในขาลง

**ความเสี่ยงที่ต้องระวัง**

- **Cyclicality (วัฏจักรของอุตสาหกรรม) ยังไม่หายไป** — Capex ปี 2026 ของ Micron $25 พันล้านดอลลาร์ + SK Hynix $29 พันล้านดอลลาร์ รวม $54 พันล้านดอลลาร์ — ถ้ากำลังการผลิตใหม่ไหลเข้าตลาดในปี 2027-2028 พร้อมกัน เสี่ยงต่อภาวะ Oversupply (สินค้าล้นตลาด)
- **Samsung เริ่มส่งมอบ HBM4 ในปริมาณเชิงพาณิชย์แล้ว** — เป็นภัยคุกคามด้านราคาและส่วนแบ่งตลาดในปี 2026-2027
- **AI Capex Slowdown Risk** — ถ้า Hyperscaler ถูกกดดันให้เร่งสร้างผลตอบแทนจากการลงทุน อาจชะลอการสั่งซื้อในช่วงปลายปี 2027
- **Insider Selling** — Chief Business Officer Sumit Sadana ขายหุ้นออกราว $10 ล้านดอลลาร์ที่ระดับ ~$421 เป็นสัญญาณหนึ่งที่ตลาดเฝ้าดู
- **Valuation ตึง** — ราคาที่ระดับ ATH สะท้อน Earnings Q2-Q3 ที่ดีไว้แล้ว ถ้าเดือนมิถุนายน (ผลประกอบการ Q3) ออกมาผิดคาดแม้นิดเดียว อาจตอบสนองรุนแรง

**3 สถานการณ์ที่อาจเกิด**

- **Bull Case (โอกาส 35%):** HBM4 Qualification กับ NVIDIA ผ่านในไตรมาสนี้ + Hyperscaler ยืนยัน Capex 2027 ขึ้นต่อ → ราคาทดสอบเป้า $660-700 ภายใน Q3-Q4
- **Base Case (โอกาส 45%):** Earnings Q3 ออกมาตามคาด ราคา Consolidate ในกรอบ $480-560 ระหว่างรอความชัดเจนของวัฏจักร 2027
- **Bear Case (โอกาส 20%):** ตลาดเริ่มกังวล Oversupply ปี 2028 + Samsung ตัดราคา → กลับสู่ระดับ $400-450 (โดยที่ EPS ยังเติบโตอยู่)

**สำหรับนักลงทุนไทย**

ช่องทางลงทุนตรง:
- **MICRON03 (DR ของ Pi Securities)** — ซื้อขายในตลาดไทยด้วยเงินบาท ผ่านบัญชีหุ้นไทยปกติ ไม่ต้องเปิดบัญชีต่างประเทศ
- กำไรจากการขาย DR **ได้รับการยกเว้นภาษี Capital Gains** (กำไรจากการขายหุ้น) — ต่างจากการซื้อหุ้นต่างประเทศตรงที่ต้องเสีย 15% เมื่อนำเงินกลับเข้าไทย (กฎใหม่ ม.ค. 2024)
- เงินปันผลจาก DR ถูกหักภาษี ณ ที่จ่าย 10% (เหมือนหุ้นไทย) — ไม่ต้องนำมารวมคำนวณภาษีบุคคลธรรมดาอีก
- ความเสี่ยงค่าเงิน: DR ไม่ได้ Hedge ค่าเงิน — ราคาจะเคลื่อนไหวตามทั้งราคาหุ้นแม่ + อัตราแลกเปลี่ยน USD/THB

ช่องทางอ้อม — กองทุน FIF (Foreign Investment Fund / กองทุนรวมที่ลงทุนในต่างประเทศ):
- กองทุนกลุ่มเทคโนโลยีโลก หรือกองทุน Semiconductor เฉพาะกลุ่ม (เช่น KT-WTAI, SCBSEMI) ที่มี MU เป็นหนึ่งในพอร์ต — เหมาะกับนักลงทุนที่ไม่อยากถือหุ้นเดี่ยว

หุ้นไทยที่เกาะธีมเดียวกัน (AI Memory Supercycle):
- **DELTA Electronics (DELTA)** — ผู้ผลิตอุปกรณ์ Power สำหรับ AI Data Center โดยตรง ได้ประโยชน์ทุกครั้งที่ Hyperscaler Capex เพิ่ม
- **KCE Electronics (KCE)** — ผลิต PCB (แผ่นวงจรพิมพ์) คุณภาพสูงสำหรับเซิร์ฟเวอร์
- **Hana Microelectronics (HANA)** — รับจ้างประกอบและทดสอบชิป Memory และ Sensor
- **Gulf Energy Development (GULF)** — ผู้ขายไฟให้ Data Center ของ Hyperscaler ในไทย

ผลกระทบต่อค่าเงินและภาพรวม:
- ดอลลาร์แข็งจากดอกเบี้ย Fed ที่ค้างนาน → บาทอ่อน → DELTA/KCE/HANA ที่ส่งออกเป็น USD ได้ประโยชน์เพิ่ม
- แต่ Foreign Inflow เข้า SET อาจชะลอ — กระทบกลุ่มธนาคาร (KBANK/SCB) และท่องเที่ยว (AOT)

คำแนะนำในการบริหาร Position (ขนาดของการถือ):
- หุ้นที่ขึ้นมา 70%+ ใน 4 เดือน — **ห้ามไล่ราคา** ที่ระดับสูงสุดใหม่
- ถ้ายังไม่มีในพอร์ต พิจารณา DCA (Dollar-Cost Averaging) แทนการซื้อก้อนใหญ่ครั้งเดียว
- ถ้าถืออยู่แล้ว Trailing Stop ช่วยปกป้องกำไร — Beta ของ MU สูงราว 1.6 (เคลื่อนไหวแรงกว่าตลาดราว 60%)
- Position Size แนะนำสำหรับนักลงทุนทั่วไป: ไม่เกิน 5% ของพอร์ตหุ้นต่างประเทศ เพราะเป็น Single Stock Concentration Risk

- HBM4 Qualification กับ NVIDIA — ถ้าผ่าน จะเป็น Catalyst (ตัวกระตุ้น) ใหญ่
- การขยายกำลังการผลิตของ SK Hynix และ Samsung ในรอบครึ่งหลังของปี
- ราคา DRAM Spot Price รายสัปดาห์ — ถ้าเริ่มอ่อนตัว เป็นสัญญาณเตือนแรก
- ค่า USD/THB — ถ้าทะลุ 36 จะกดดัน DR ของหุ้นต่างประเทศที่ราคาในบาท
